# AMPL Holding Page

Coming-soon page for **AMPL** (`stayampl.com`).

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Edit copy & socials

Update [`src/lib/site.ts`](src/lib/site.ts).

## Deploy on Vercel

1. Import this repo in [Vercel](https://vercel.com/new)
2. Framework: Next.js (auto-detected)
3. Deploy, then add `stayampl.com` under Project → Settings → Domains
